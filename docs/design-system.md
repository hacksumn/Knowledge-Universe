# Design system

Near-black navy #080C16 canvas, slightly elevated #0C111D panels, subtle borders, restrained lavender emphasis. Inter for interface text; JetBrains Mono for technical labels; system fallbacks when font loading is unavailable.

Domains: lavender AI/LLMs; blue agents; teal infrastructure; amber betting; pink prediction models; lime PCB diagnostics. Labels and inspector domain names accompany colors. Spheres use emissive shaded materials and low-opacity halos; cross-domain edges are dashed. No starfield, permanent particle animation or expensive bloom.

The canvas dominates the page. Independent panels collapse; immersive mode removes both. Small screens begin with panels closed. Camera animation defaults to the system reduced-motion preference. Keyboard controls, visible focus styles and readable HTML inspector content accompany the WebGL view.
