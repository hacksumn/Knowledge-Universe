# Product specification — Milestone 1

Knowledge Universe is a personal technical knowledge explorer. The central interface is an interactive Three.js scene, not a static mind map. Six connected domains cover AI/LLMs, AI agents, data centers, sports betting, prediction models and PCB diagnostics.

This release implements the 3D prototype: at least 60 meaningful deterministic concepts; six colors; orbit/pan/zoom; node selection and focusing; title/description search; domain filtering; a responsive inspector; relationship context; independently collapsible panels; immersive mode; keyboard navigation; reduced-motion-aware camera transitions; session-only node pinning.

The inspector provides concise educational summaries and curated relationship explanations. Demo links are explicitly unverified. Later milestones, including persistent graph CRUD, provider-backed expansion, generated explanations, research, imports, bookmarks and usage metering, are not authorized in this first pass.

Data resets on reload. No API keys or paid services are needed.
